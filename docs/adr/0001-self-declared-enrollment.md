# 学校Google本人確認と参加年度申告で学生参加資格を判定する

学校Google本人確認と必須の入学年度・卒業予定年度の自己申告を通常の参加条件とし、手動の在籍審査や証明書提出を必須工程にしない。登録負担を抑える方針を採用し、学校による在籍認定を表す表示は使わない。PRD原文は変更せず、以前の運営審査を前提にした準備と区別する。

本アプリの年度は日本時間4月1日から翌年3月31日までとする。参加期間は入学年度の4月1日から卒業予定年度の翌年4月1日まで（終端を含まない）で、学校の正式な学事暦や修業年限を推測しない。公開学年表示から年度を補完しない。本人の年度訂正・私的データの読取や整理・ログアウトと、学生の新規投稿・参加を分け、停止・削除状態を年度変更で解除しない。

入力名は「入学年度」「卒業予定年度」とし、例えば2028年3月卒業予定なら2027年度と案内する。同一年度の入学・卒業予定を許容する。入力は1900〜2199の整数で、卒業予定年度が入学年度以降であることだけを確認し、学科の修業年限や本人の現在年度を推測して補わない。

申告年度は非公開とし、公開プロフィールやGoogle由来の名前・写真・メールへ自動連携しない。最終の投稿・参加処理で保存値とサーバー時刻を確認する。初回入力と訂正には同じ2項目を用い、年度更新に人手審査を挟まない。実認証・投稿の接続には、既存のログ・私的データ・運営・通知等の公開条件も引き続き適用する。
