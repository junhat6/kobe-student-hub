# 次の探索・学生試用の候補 — 修正前の画面監査

今回新たに取得した公開プレビューの架空サンプル画面を基にした比較です。実学生の経験・需要・価値の証明ではありません。この記録は修正前の読取監査で、修正後の状態は別のQA記録を参照します。

## 観察した手順と状態

Playwright ChromiumでPC幅とiPhone 13相当の画面幅を使用。各画面を保存して開き、読み込み中の本文画像は破棄して本文・コード表示後に撮り直しました。以下の画像名は両画面幅に対応します。画像・画面記録はローカルだけに保持し、この文書には添付・公開しません。

1. ホームを見る：正常。架空サンプル・ログイン準備中の表示がある。記事・作品、読了時間、概要、タグ、投稿者を表示。画像 `01-home-*`。
2. Gitテーマで絞る：正常。`/search?tag=Git` に記事1件が表示される。通常カードでは詳細な前提・読後の見通しはまだ表示されない。画像 `02-select-*`。
3. 記事を読む：正常。想定読者・前提知識・読後の見通し、練習前の条件、編集とコマンドの手順、コピー／選択操作が表示される。画像 `03-read-*` は本文取得完了後のもの。
4. 投稿者を見る：正常。サンプルの先輩の紹介と同じ投稿者の記事が並ぶ。見えている根拠は記事であり、このサンプルから実績・作品・本人の専門性まで証明できない。画像 `04-author-*`。
5. 投稿者の「← 一覧へ」を押す：探索条件が失われる。両画面幅で、先ほどのGit1件ではなく `/` の4件へ移る。画像 `05-author-return-*`。混乱や離脱を起こすかは未検証。
6. 既存カードA／Bを比べる：表示は正常。どちらも同じ3記事・同じ順序。Bは前提と読後の見通しを加え、特に縦並びのモバイルでは各カードが長くなる。画像 `06-context-b-*`、`07-context-a-*`。

## 事実から選ぶ次の単位

| 候補 | 今回の根拠 | まだ仮説である部分 | 最小の次の確認 |
| --- | --- | --- | --- |
| 探索条件を保って活動をたどる | 手順2→3→4→5で絞り込みが消えた。記事から投稿者へは移れる | 投稿者を見たあとも元の探索を続けたい、条件の消失で迷う | 技術的には限定した条件引継ぎの修正候補。直接リンク・新規タブ・他の記事を経由した場合も安全な戻り先を独立QAする。学生には戻ろうとする場所を先に誘導せず観察 |
| H02：読む前に自分に合うと判断できる | 通常カードは時間と概要。記事とBには明示的な前提・読後の説明がある。Bの縦の長さも確認 | 情報追加で判断しやすくなるか、用語や長さが負担か。「短いほど良い」とは限らない | [既存計画](CARD-STUDY.md) でA／Bの順番を入れ替え、選択理由と読後の期待との差を聞く。欄や推薦機能を増やさない |
| E23：読んだ経験を自分で試す | Git記事は練習用リポジトリの前提、手作業、差分確認を分けている。「4分」は読む目安として表示される | 練習環境を準備できるか、読む時間と試す時間を区別するか、結果の意味を理解できるか | 希望者だけが合意した使い捨て環境で試す既存計画へ。コピー成功やコマンド完了を理解・価値の指標にしない |
| 記事から活動を理解する | 著者ページで他の記事へ進めるが、架空の紹介と少数の記事しか根拠がない | 記事が著者への理解を助けるか、同著者の次の記事を読みたいか | 読んだ根拠と推測を本人に分けてもらう。活動項目・人物検索・フォローを先に追加しない |
| ローカル新着導線 | 今回は再監査していない。既存の [RECENT-FEED.md](RECENT-FEED.md) とQAは動作証拠 | 新着順で自分向けの経験を見つけられるか | 学生試用が記事選択を問う段階ならH02を先に使う。ローカル投稿の動作成功を需要の証拠へ転用しない |

**提案：** コード変更を選ぶなら、再現済みの探索条件消失を最小範囲で直す候補が最も根拠が明確です。ただし影響度や学生価値の順位は未確定です。価値検証では、既に比較画面と計画が揃うH02を最初に置き、E23は本人が実践を希望する場合の後続にします。修正の有無と価値検証の結論は分けて記録します。

## アクセシビリティと限界

狭い画面でも本文・前提欄は折り返され、確認した記事・著者画面に横方向のはみ出しはありませんでした。一方、長いBカードでは次候補までのスクロール量が増え、小さな補足文字・タグ・戻り導線の読み取りや操作の負担は残る確認事項です。見た目だけでコントラスト適合、タッチ精度、キーボード順、スクリーンリーダー、拡大表示の適合を保証しません。

今回は読取と画面遷移の監査です。コピー・クリップボード・Git実行、ブラウザ履歴による位置／フォーカス復元、実iPhone／Safari・実IME、実認証・投稿・運営は検証していません。学生への質問や回答収集も行っていません。新たな通知・同意・保持ルールをこの比較で決めてはいません。
