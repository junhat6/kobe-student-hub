# 最初の実ユーザー利用までの残条件

[公開 Issue #38](https://github.com/junhat6/kobe-student-hub/issues/38) と既存設計・QAの入口をまとめたものです。PRDを変更したり、未決定の規約・責任者・窓口を決めたりする文書ではありません。個別の検証範囲はリンク先を優先します。

## 実ユーザー接続前のゲート

「必要な証拠」は既存条件の確認方法であり、取得済みという意味ではありません。実ユーザーの認証・投稿を開く前に、対象の接続に関係する未完了条件を解消します。

## 学生・実端末で確かめること

[既存の小人数試用計画](CARD-STUDY.md) を使い、読む前の見通し、記事選択、活動への理解、次に試したい行動を本人の言葉で確かめます。役立たない・選ばないという観察も残し、機能を増やすこと自体を成功にしません。参加条件、同意、私的記録の保存・保持を整理し、生の回答や個人情報は公開Issueへ載せません。

物理PC・スマートフォンでは、実際のブラウザ・認証・入力・画面遷移・必要なコピー操作を確認します。実IME、Cookie、端末固有の動作をエミュレーションの結果から推定しません。学生価値と端末動作は別々に記録します。

## 再開するとき

未完了ゲートのうち次の一つを選び、必要な外部設定／判断、実装、独立QA、証拠、次の判断を [WORK.md](WORK.md) と Issue #38 へ対応づけます。実接続の証拠は対象範囲と限界を明示し、設定・認証情報・生ログ等の私的運用情報はこの公開文書へ転記しません。未決定を埋めるためだけの機能追加や、架空の成功表示は行いません。


初回の資格確認待ち申請は、通常ログインとは別のローカルserver-only経路で検証します。[PENDING-REGISTRATION.md](PENDING-REGISTRATION.md)を参照。pendingの受付は在籍認定・active化・session発行ではなく、実登録・実ログインの提供でもありません。
